Import Trade History

No login, no password — export a CSV from Tradovate and drop it in below. The file is read entirely in your browser; nothing gets uploaded anywhere.

  1. Log into Tradovate: trader.tradovate.com (opens in a new tab)
  2. Click your account name at the top, then the small gear icon next to it — this opens Account Reports (some versions show this as a Reports item in the main menu instead)
  3. Click the Account Balance History tab — not Client Statements or Performance, those are different reports (Cash History also works if that's what you've got)
  4. Set the date range back to the day you first opened the account, so it captures everything
  5. Click Download Report to save the CSV
  6. Come back here and upload that file below
Auto-fills Net P&L and Best Day below once uploaded. Cash History files are also accepted.

On the 25K Flex, the Max Loss Limit is a fixed $1,000; the Daily Loss Limit is a separate, optional setting — OFF by default, or a firm-enforced $600 if you opted into it (the 50K Flex carries the same optional setting at a $1,200 cap, with a $2,000 Max Loss Limit). LucidPro offers the same OFF/$600 Daily Loss Limit choice at every account size, and LucidDaily lets you choose Intraday or End-of-Day drawdown tracking — both toggled above. Eval and reset pricing is populated for the 25K Flex and all four LucidPro sizes, taken directly from Lucid's own checkout screen at the time this was written. Every price changes with Lucid's current promos, so treat these as a snapshot, not what you'll pay today.
