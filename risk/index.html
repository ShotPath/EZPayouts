This page only reads and changes your account's risk settings. It never places or cancels orders.

Where do I get an API key?
  1. Sign in at trader.tradovate.com, open the menu, then Application Settings → API Access.
  2. Turn on API access (Tradovate may charge for it), then click Generate API Key.
  3. Copy the cid and the secret into the boxes above. The secret is only shown once.

Prop firm accounts often don't allow API keys, and the firm may control these settings itself.
