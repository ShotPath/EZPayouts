Setup

Set it up in about 2 minutes.

It isn't in the Chrome Web Store yet, so you add it by hand. Six steps, no coding. Take them one at a time.

  1. 1

    Download the extension

    Click the button. A file called ezpayouts-chart-skins.zip lands in your Downloads folder.

    Download the zip
    ezpayouts-chart-skins.zipDone
  2. 2

    Unzip it into a folder you'll keep

    Windows: right-click the zip, choose Extract All…, then Extract.
    Mac: double-click the zip.

    You get a folder called ezpayouts-chart-skins. Move it somewhere safe, like Documents.

    Chrome runs the extension from this folder, so don't delete it later.

    →ezpayouts-chart-skins
  3. 3

    Open the extensions page

    Click Chrome's address bar (where website addresses go), type chrome://extensions and press Enter.

    Websites can't open this page for you, so copy and paste it if typing is a pain. Edge also accepts edge://extensions, Opera opera://extensions.

    chrome://extensions
  4. 4

    Turn on Developer mode

    Find the Developer mode switch in the top-right corner of that page and turn it on.

    In Edge it's in the left menu, near the bottom. It's a normal Chrome setting; it just lets you add extensions from a folder.

    Developer mode
  5. 5

    Click "Load unpacked" and pick the folder

    Three new buttons appear at the top-left. Click Load unpacked, open the ezpayouts-chart-skins folder from step 2, and click Select Folder.

    If there's a second folder with the same name inside it, open that one. The right folder has a file called manifest.json in it.

    Load unpackedPack extensionUpdate
  6. 6

    Pin it, then open a chart

    Click the puzzle-piece icon next to the address bar, then the pin next to EZPayouts Chart Skins. The EZ icon now stays in your toolbar.

    Open a chart on TradingView, click the EZ icon and pick a skin. Done.

    Tip: TradingView's dark theme (menu → Dark theme) keeps the labels easy to read over a skin.

Questions

Good to know.

Is it safe?

It only changes how the chart looks. It skips the one step where the chart paints its background, so the skin behind shows through. It doesn't read your symbols, orders or account, and it never trades.

The code is plain and open: every file is in the folder you unzipped.

Why do I need Developer mode?

Chrome only lets you add extensions from a folder when Developer mode is on. It's there for exactly this. Once Chart Skins is in the Chrome Web Store you'll be able to install it with one click instead.

Will it slow down TradingView?

The skin draws on its own, at 30 frames a second by default, and pauses when the tab isn't visible. If your computer struggles, it draws at a lower resolution automatically. You can also pick a still image or turn it off with Alt+Shift+B.

Can I use it on my prop firm's platform?

It works on many sites that use TradingView's charts: open the site, click the EZ icon, then Turn on here. Some firms don't allow browser extensions on evaluation or funded accounts, so check your firm's rules first.

How do I update it?

Download the new zip and unzip it over your old folder (replace the files). Then open chrome://extensions and click the round reload arrow on the EZPayouts Chart Skins card.

Does it work in Safari or Firefox?

Not yet. It works in Chrome and browsers built on it: Brave, Edge, Arc and Opera.

It's installed but my chart looks the same.

Refresh the TradingView tab once (it needs to load after the extension). Then click the EZ icon and make sure the switch at the top is on. If you pressed Alt+Shift+B, press it again.
